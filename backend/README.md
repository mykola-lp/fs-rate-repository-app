# Backend

This directory contains the [Rate Repository API](https://github.com/fullstack-hy2020/rate-repository-api), which provides the GraphQL API and database used by the mobile application.

The backend is provided as part of the Full Stack Open course. No changes were made to the API itself.

For complete documentation and setup instructions, see the [original repository](https://github.com/fullstack-hy2020/rate-repository-api).

## Running the Backend

Follow the setup instructions in the original repository, then start the API with:

```bash
npm start
```

The GraphQL API will be available at:

```text
http://localhost:4000
```
